# briansalazar.dev

Personal portfolio — Head of Support at Penida.io, product-adjacent, builder.

**Live:** https://briansalazar.dev

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- next-intl (English + Spanish)
- Deployed on Vercel
- DNS via Cloudflare

## Local dev

```bash
npm install
npm run dev
```

Open http://localhost:3000
